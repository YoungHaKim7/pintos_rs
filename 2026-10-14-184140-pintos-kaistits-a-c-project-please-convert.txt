  ## 1. Target decision: custom JSON + `-Zbuild-std=core`, **code-model
  `large`** (NOT `kernel`)

  **The stock `x86_64-unknown-none` target cannot work**: it ships prebuilt
  `core` compiled with the **small** code model (absolute refs via 32-bit
  sign-extended `R_X86_64_32S`). The kernel links at VMA 0x8004200000 (~513 GB)
  — beyond ±2 GB — so linking prebuilt core yields `relocation truncated to fit:
  R_X86_64_32S`. `RUSTFLAGS -C code-model=large` does not affect the prebuilt
  core. Hence core must be rebuilt from source: nightly + `-Zbuild-std=core`
  (both already available).

  **Critical correction vs the BOOTBOOT reference
  (`rust_kernel/triplets/mykernel-x86.json` uses `"code-model": "kernel"`)**:
  LLVM's *kernel* code model assumes symbols in the **top 2 GB**
  (0xffffffff80000000–0xffffffffffffffff); the BOOTBOOT demo links at
  0xffffffffffe02000 so it worked there. Pintos at 0x8004200000 is NOT in that
  window — `kernel` model would silently miscompile. Use **`"code-model":
  "large"`** (exact equivalent of the C build's `-mcmodel=large`). Also switch
  `relocation-model` from the reference's `pic` to `static` (C uses `-fno-pic`;
  avoids generating GOT-based accesses that would need `.got` in the script) and
  `has-elf-tls` to `false` (pintos has no TLS/%fs setup).

  ## 3. build.rs — gcc-objects approach (recommended over
  `global_asm!(include_str!)`)

  Assemble the three kernel `.S` files with **gcc exactly as the C build does**
  (`gcc -c -Wa,--gstabs -mcmodel=large -I pintos-kaist/include` — intr-stubs.S's
  CPP `STUB` macro, token pasting, `.func/.endfunc`, and .text/.data
  interleaving are all handled by GNU cpp+as with zero porting risk; LLVM-MC
  support for `.func` is not guaranteed), then pass each `.o` **directly on the
  link line** via `cargo:rustc-link-arg=<abs path>`. Direct object files are
  always fully included (no archive pull-in semantics, no `-l:`parsing risk).
  Also preprocess the linker script here.

  Logic:
  1. `let out = OUT_DIR; let pintos = CARGO_MANIFEST_DIR + "/pintos-kaist"`.
  2. Linker script: `gcc -E -P -o {out}/kernel.lds {crate}/kernel.lds.S
  -I{pintos}/include` — **`-P` is mandatory** (without it cpp emits `# NN
  "file"` line markers which are syntax errors in a linker script; the C build
  adds exactly `CPPFLAGS += -P`). Emit
  `cargo:rustc-link-arg=-T{out}/kernel.lds`. Keep a crate-local adapted
  `kernel.lds.S` (below) rather than pointing at pintos-kaist's, keeping the
  reference tree pristine.
  3. For each of `pintos-kaist/threads/start.S`,
  `pintos-kaist/threads/intr-stubs.S`, `pintos-kaist/userprog/syscall-entry.S`:
  `gcc -c {src} -o {out}/asm/{name}.o -Wa,--gstabs -mcmodel=large
  -I{pintos}/include`; emit `cargo:rustc-link-arg={out}/asm/{name}.o` (after the
  -T arg). Use absolute paths everywhere.
  4. Also emit `cargo:rustc-link-arg=--no-relax` (lld supports it; mirrors
  `LDFLAGS`).
  5. `cargo:rerun-if-changed=` for each `.S`, `kernel.lds.S`, and
  `pintos-kaist/include/threads/loader.h`.
  6. Panic on non-zero exit with captured stderr (fail the build loudly).

  Fallback considered and rejected: `global_asm!(include_str!(OUT_DIR
  preprocessed))` — needs `-P` stripping anyway, `.func/.endfunc`/`.section`
  switching under LLVM MC is unproven, and Rust-side `#[unsafe(no_mangle)]`
  symbol interplay adds risk. gcc objects keep the asm byte-identical to the C
  kernel.

  ## 7. Pitfalls (ordered by severity)

  1. **Code model**: must be `large`, not `kernel` (kernel = top-2GB assumption;
  0x8004200000 violates it). This is the one intentional divergence from
  rust_kernel/triplets/mykernel-x86.json. Stock `x86_64-unknown-none` is
  unusable for the same reason (prebuilt small-model core → R_X86_64_32S
  truncation).
  2. **`--gc-sections`**: rustc passes it by default for ELF executables.
  `_start` is an absolute symbol (not a section symbol) so it is NOT a GC root —
  without `KEEP(*(.entry))` the entire bootstrap + boot page tables get
  stripped and the disk boots into garbage. Also ensure `intr_stubs` (`.data`
  from intr-stubs.o) is referenced by the Rust IDT-init code or add
  `KEEP(*(.data))`.
  3. **Linker-script preprocessing must use `-P`** (strip `#` line markers —
  they are linker-script syntax errors). gcc `-E` on `.S` runs the assembler
  preprocessor; include path `-Ipintos-kaist/include` resolves
  `"threads/loader.h"`.
  4. **Padding before page count**: `dd conv=sync` pads kernel.bin to a 4096
  multiple BEFORE `KERNEL_LOAD_PAGES = size/4096` is computed (loader raw-reads
  `KERNEL_LOAD_PAGES*8` sectors to 0x200000; a short tail would leave garbage).
  5. **`objcopy -O binary` semantics**: uses **LMA** for file placement (VMA≠LMA
  handled — output starts at LMA 0x200000, exactly what the loader jumps to);
  NOBITS `.bss` is excluded from the flat binary automatically — but `.bss` in
  RAM is real, so `bss_init` must zero `_start_bss.._end_bss`; extend the `.bss`
  pattern (`.bss.* .sbss*`) or Rust BSS lands as orphans past `_end_bss` and is
  never zeroed.
  6. **Symbol contracts from asm**: `main` (start.S), `intr_handler`
  (intr-stubs.S), `syscall_handler` (syscall-entry.S), later `kernel_thread` —
  all must be `#[unsafe(no_mangle)] pub extern "C" fn` with exact names and SysV
  ABI; asm may clobber registers per that ABI. `#![no_main]` prevents rustc
  emitting its own `main`; no crt0/startup objects are linked (`os = none`,
  `no-default-libraries`).
  7. **Panic plumbing**: target `panic-strategy: abort` AND `[profile.*] panic =
  "abort"` must agree, plus a `#[panic_handler]`; rustc can still emit
  `.eh_frame` — the `/DISCARD/` removes it (matches the C script; unwinding
  relies on frame pointers, which `eliminate-frame-pointer: false` preserves for
  utils/backtrace's rbp-chain walk).
  8. **Red zone / SSE / stack protector**: `disable-red-zone: true` +
  `-mmx,-sse,+soft-float` (interrupt path clobbers below rsp; no FPU state) and
  `-C stack-protector=none` (parity with the C build).
  9. **Edition 2024 syntax**: `#[unsafe(no_mangle)]` and `unsafe extern "C" {
  ... }` blocks (nightly 1.100 supports edition 2024).
  10. **pintos runner quirks**: CWD must contain os.dsk (hardcoded relative
  path); kernel args max **128 bytes** NUL-packed; `--` separates runner flags
  from kernel args; `-T N` is a subprocess timeout; missing fs/swap disks are
  silently omitted (fine for threads, use `--fs-disk=4`/`disks` recipe later);
  `-cpu qemu64` means no fancy instructions (no rdrand etc.); the temp
  arg-patched os.dsk copy lives in /tmp and is auto-deleted.
  11. **.S object placement**: objects passed via `cargo:rustc-link-arg` land on
  the final link line after Rust rlibs — irrelevant for correctness (direct .o
  files are always included; `*(.entry)` wildcard collects them regardless of
  order).
  12. **`__udivdi3`-style shims**: unneeded in Rust (native 64-bit div;
  compiler-builtins ships with `-Zbuild-std` anyway).

      499 +/* List-less function comparing two threads by priority for   
      500 +list_insert_ordered/list_max on the ready list and semaphore  
      501 +waiter lists.  Returns true if A's thread has strictly higher 
      502 +priority than B's. */                                         
      503 +pub unsafe fn thread_cmp_priority(                            
      504 +    a: *const ListElem,                                       
      505 +    b: *const ListElem,                                       
      506 +    _aux: *mut (),                                            
      507 +) -> bool {                                                   
      508 +    unsafe {                                                  
      509 +        let ta = list_entry::<Thread>(a as *mut ListElem, Thre
          +ad::ELEM_OFFSET);                                             
      510 +        let tb = list_entry::<Thread>(b as *mut ListElem, Thre
          +ad::ELEM_OFFSET);                                             
      511 +        (*ta).priority > (*tb).priority                       
      512 +    }                                                         
      513 +}                                                             
      514 +                                                              
      515 +/* Refreshes the current thread's effective priority from its 
      516 +donations: the effective priority is the max of the original  
      517 +priority and the highest priority among the waiters of every l
          +ock                                                           
      518 +this thread holds (transitively through donation chains). */  
      519 +pub unsafe fn thread_donate_priority() {                      
      520 +    unsafe {                                                  
      521 +        let t = thread_current();                             
      522 +        let donated = max_donated_priority(t);                
      523 +        let effective = if (*t).original_priority > donated { 
      524 +            (*t).original_priority                            
      525 +        } else {                                              
      526 +            donated                                           
      527 +        };                                                    
      528 +        if effective != (*t).priority {                       
      529 +            (*t).priority = effective;                        
      530 +        }                                                     
      531 +    }                                                         
      532 +}                                                             
      533 +                                                              
      534 +/* Walks the lock graph rooted at T and returns the highest   
      535 +donated priority (PRI_MIN if there are no donations). */      
      536 +unsafe fn max_donated_priority(t: *mut Thread) -> i32 {       
      537 +    unsafe {                                                  
      538 +        let mut max = PRI_MIN;                                
      539 +        let mut e = list_first(&(*t).acquired_locks);         
      540 +        while !list_last(&(*t).acquired_locks, e) {           
      541 +            let lock = list_entry::<Lock>(e, LOCK_ELEM_OFFSET)
          +;                                                             
      542 +            /* The lock's semaphore waiters are the candidate 
      543 +            donors (kept priority-ordered by synch.rs). */    
      544 +            let sema = &raw mut (*lock).semaphore;            
      545 +            let mut w = list_first(&(*sema).waiters);         
      546 +            while !list_last(&(*sema).waiters, w) {           
      547 +                let waiter = list_entry::<Thread>(w, Thread::E
          +LEM_OFFSET);                                                  
      548 +                if (*waiter).priority > max {                 
      549 +                    max = (*waiter).priority;                 
      550 +                }                                             
      551 +                w = list_next(w);                             
      552 +            }                                                 
      553 +            e = list_next(e);                                 
      554 +        }                                                     
      555 +        max                                                   
      556 +    }                                                         
      557 +}

      562 +link: we reuse lock.semaphore.waiters' head element is NOT saf
          +e,

      596 +    x / n

      601 +    ((x as i128) * (y as i128) >> FSHIFT) as i64              
      602 +}                                                             
      603 +                                                              
      604 +#[inline]

      606 +    (((x as i128) << FSHIFT) / (y as i128)) as i64            
      607 +}

      618 +/* load_avg = (59/60)*load_avg + (1/60)*ready_threads. */     
      619 +unsafe fn mlfqs_update_load_avg() {                           
      620 +    unsafe {                                                  
      621 +        let ready = ready_threads_cnt() as i64;               
      622 +        let coef = fp_div(fp_mul_int(59 * F, 1), 60 * F);     
      623 +        let one_sixtieth = fp_div(F, 60 * F);                 
      624 +        LOAD_AVG = fp_add(fp_mul(LOAD_AVG, coef), fp_mul_int(o
          +ne_sixtieth, ready));                                         
      625 +    }                                                         
      626 +}

      628 +/* recent_cpu = (2*load)/(2*load+1) * recent_cpu + 1, all thre
          +ads. */                                                       
      629 +unsafe fn mlfqs_foreach_update_recent_cpu() {                 
      630 +    unsafe {                                                  
      631 +        thread_foreach(mlfqs_update_recent_cpu, core::ptr::nul
          +l_mut());                                                     
      632 +    }

      634 +                                                              
      635 +unsafe fn mlfqs_update_recent_cpu(t: *mut Thread, _aux: *mut (
          +)) {                                                          
      636 +    unsafe {                                                  
      637 +        if t == IDLE_THREAD {                                 
      638 +            return;                                           
      639 +        }                                                     
      640 +        let twice_load = fp_mul_int(LOAD_AVG, 2);             
      641 +        let coef = fp_div(twice_load, fp_add_int(twice_load, 1
          +));                                                           
      642 +        (*t).recent_cpu = fp_add_int(fp_mul(coef, (*t).recent_
          +cpu), 1);                                                     
      643 +    }                                                         
      644 +}

      648 +    unsafe {

      652 +        let priority = PRI_MAX as i64                         
      653 +            - fp_round_to_zero(fp_div_int((*t).recent_cpu, 4))
      654 +            - ((*t).nice as i64) * 2;                         
      655 +        (*t).priority = priority.clamp(PRI_MIN as i64, PRI_MAX
          + as i64) as i32;                                              
      656 +    }

      699 +unsafe extern "C" fn idle(aux: *mut ()) {                     
      700 +    unsafe {                                                  
      701 +        let idle_started = aux as *mut Semaphore;             
      702 +                                                              
      703 +        IDLE_THREAD = thread_current();                       
      704 +        crate::threads::synch::sema_up(idle_started);         
      705 +                                                              
      706 +        loop {                                                
      707 +            /* Let someone else run. */                       
      708 +            intr_disable();                                   
      709 +            thread_block();                                   
      710 +                                                              
      711 +            /* Re-enable interrupts and wait for the next one.
      712 +                                                              
      713 +            The `sti' instruction disables interrupts until th
          +e                                                             
      714 +            completion of the next instruction, so these two  
      715 +            instructions are executed atomically.  This atomic
          +ity                                                           
      716 +            is important; otherwise, an interrupt could be han
          +dled                                                          
      717 +            between re-enabling interrupts and waiting for the
      718 +            next one to occur, wasting as much as one clock ti
          +ck                                                            
      719 +            worth of time. */                                 
      720 +            core::arch::asm!("sti; hlt", options(preserves_fla
          +gs, nomem, nostack));                                         
      721 +        }                                                     
      722 +    }

      761 +    unsafe {                                                  
      762 +        if list_empty(&raw const READY_LIST) {

      770 +/* Switching the thread by activating the new thread's page   
      771 +tables, and, if the previous thread is dying, destroying it. *
          +/                                                             
      772 +unsafe fn do_schedule(status: ThreadStatus) {                 
      773 +    unsafe {                                                  
      774 +        crate::ASSERT!(intr_get_level() == IntrLevel::Off);   
      775 +        crate::ASSERT!((*thread_current()).status == ThreadSta
          +tus::Running);                                                
      776 +        while !list_empty(&raw const DESTRUCTION_REQ) {       
      777 +            let victim = list_entry::<Thread>(                
      778 +                list_pop_front(&raw mut DESTRUCTION_REQ),     
      779 +                Thread::ELEM_OFFSET,                          
      780 +            );                                                
      781 +            palloc_free_page(victim as *mut u8);              
      782 +        }                                                     
      783 +        (*thread_current()).status = status;                  
      784 +        schedule();                                           
      785 +    }                                                         
      786 +}                                                             
      787 +                                                              
      788 +unsafe fn schedule() {                                        
      789 +    unsafe {                                                  
      790 +        let curr = running_thread();                          
      791 +        let next = next_thread_to_run();                      
      792 +                                                              
      793 +        crate::ASSERT!(intr_get_level() == IntrLevel::Off);   
      794 +        crate::ASSERT!((*curr).status != ThreadStatus::Running
          +);                                                            
      795 +        crate::ASSERT!(is_thread(next));                      
      796 +        /* Mark us as running. */                             
      797 +        (*next).status = ThreadStatus::Running;               
      798 +                                                              
      799 +        /* Start new time slice. */                           
      800 +        THREAD_TICKS = 0;                                     
      801 +                                                              
      802 +        /* Activate the new address space. */                 
      803 +        crate::userprog::process::process_activate(next);     
      804 +                                                              
      805 +        if curr != next {                                     
      806 +            /* If the thread we switched from is dying, destro
          +y                                                             
      807 +            its struct thread.  This must happen late so that 
      808 +            thread_exit() doesn't pull out the rug under itsel
          +f.                                                            
      809 +            We just queue the page free request here because t
          +he                                                            
      810 +            page is currently used by the stack.  The real    
      811 +            destruction logic runs at the beginning of        
      812 +            schedule(). */                                    
      813 +            if !curr.is_null()                                
      814 +                && (*curr).status == ThreadStatus::Dying      
      815 +                && curr != INITIAL_THREAD                     
      816 +            {                                                 
      817 +                crate::ASSERT!(curr != next);                 
      818 +                list_push_back(&raw mut DESTRUCTION_REQ, &raw 
          +mut (*curr).elem);                                            
      819 +            }                                                 
      820 +                                                              
      821 +            /* Before switching the thread, we first save the 
      822 +            information of the currently running thread. */   
      823 +            thread_launch(next);                              
      824 +        }                                                     
      825 +    }                                                         
      826 +}
